# Polaris Docs

This is the official Polaris documentation site. Its landing page keeps a
small number of entry points while the sidebar and top navigation follow the
fixed directory configuration.

## Start Here

- [Polaris PRD](/development/prd) is the single ground truth for product
  scope, priorities, and requirements.
- [Polaris](/polaris/) is the workflow execution platform and control plane for
  isolated environments.
- [Polaris Portal](/polaris/polaris-portal) is the browser control surface.
- [Polaris Workflow](/polaris/workflow) is the single workflow reference.
- [Development](/development/) contains the PRD, deployment, and incident
  records.

## Source Of Truth

Repository root READMEs contain source checkout, local development, and
repository-specific command instructions. Executable skills, schemas, and tool
contracts remain beside their implementations. This site contains the
cross-repository material that needs a stable, shared view, and the PRD in
[Development](/development/prd) is the single ground truth for product scope.
