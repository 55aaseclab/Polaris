# Polaris Docs

This is the official Polaris documentation site. Its landing page keeps a
small number of entry points while the sidebar and top navigation follow the
fixed directory configuration.

## Start Here

- [Polaris](/polaris/) is the workflow execution platform and control plane for
  isolated environments. The Domain Pack language is on
  [Polaris DSL](/polaris/workflow).
- [Operations](/operations/) contains gateway, deployment, and release records.

## Source Of Truth

Repository root READMEs contain source checkout, local development, and
repository-specific command instructions. Executable skills, schemas, and tool
contracts remain beside their implementations. This site contains the
cross-repository material that needs a stable, shared view.

The [Polaris 0.4.0 page](/operations/polaris-0.4.0/) is the current shipped
source baseline. The [Polaris 0.3.4 page](/operations/polaris-0.3.4/) and
[Polaris 0.3 release section](/operations/polaris-release/) remain the
previous single-host baseline and original gate record. The archived
[0.3.3 section](/operations/polaris-0.3.3/) preserves its capacity and
migration evidence. [Polaris 0.5.0](/operations/polaris-0.5.0/) is the next
local-cell and real Vault-executor slice.
