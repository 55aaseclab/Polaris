# Shared Infrastructure

This section explains how Polaris supports many people on shared
infrastructure without mixing their project environments together.

It focuses on three customer-facing outcomes:

- clear workspace isolation
- persistent workspace runtime state
- safe backend and driver switching
- runtime status and credential switching semantics
