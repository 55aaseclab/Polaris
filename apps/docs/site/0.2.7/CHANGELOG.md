# Docs Changelog

## 0.2.7 vs 0.2.6

### Added

- Local deployment packaging docs for Debian, Windows installer, and macOS
  disk image releases.
- Telemetry docs covering PostHog, Sentry, and the five release telemetry
  categories.
- Release packaging workflow notes for Linux, Windows, and macOS artifact
  generation.

### Changed

- Local deployment docs now distinguish native release packaging from
  development-only local stack entry points.
- Release metadata now treats `0.2.7` as the current frozen snapshot.
- Packaging docs now reflect `.deb`, Windows installer `.exe`, and macOS
  `.dmg` outputs.

### Notes

- `0.2.7` is the current frozen release snapshot.
- `latest` starts from this baseline.
