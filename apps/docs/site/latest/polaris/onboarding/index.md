# Onboarding

This section explains how Polaris helps a new team member reach a usable
workspace quickly.

It focuses on two customer-facing outcomes:

- a shared Docker foundation for standard workspaces
- a workspace-oriented command surface to create, start, stop, and manage
  workspaces
