# Polaris 0.3 Release Evidence

Status: **controlled test-host release**. Formal production promotion is
deferred to 0.3.2. The records below contain no credentials, cookies,
assertions, or customer data.

**Roadmap update (2026-08-06):** 0.3.1 owns performance only. 0.3.2 owns the
production perimeter. User-count growth, capacity, storage budgets, quotas,
and resource scaling are scheduled for 0.3.3. The dated evidence artifacts
below retain their original timestamps and results.

**Route update:** `/g/*` is now the only Polaris private surface gateway route. The
dated smoke records that mention `/private-surface/*` describe the former compatibility
path and are historical evidence, not a current route contract.

The current post-deploy route and vertical-startup check is recorded in the
[Polaris 0.3.4 deployment evidence](/release-evidence/0.3-20260811-polaris-0.3.4-vertical-startup.json).
It supersedes the older host snapshots for current routing, manifest, and
active-color values; the older records remain immutable historical evidence.

## Current Host Findings

The test host is currently on blue with Polaris source `c13647b` and manifest
`sha256:1a22ca7d...`. Public checks return `200` for health, readiness, Portal
routes, and Paseo assets; `401` for unauthenticated `/g/`; and `404` for the
removed `/private-surface/` route. Portal HTML and CSS declare the light scheme, and
the private surface `9090`, `32001`, and `32002` ports are neither listening nor
reachable on the host. The isolated vertical startup fixture was removed
after its health/readiness and Paseo checks passed. The remote sync excludes
untracked Paseo surface work and local `config/users` data. Signing,
provenance, SBOM, formal TLS/DNS, authenticated browser evidence, and
user-scale evidence are not 0.3.0 test-host gates.

## Release Decision

The current HTTP candidate is deployed as Polaris 0.3.4 for the bounded
`0.3.0-single-host` test-host profile. This closes the current source,
manifest, blue/green, Portal/Paseo, gateway-boundary, and vertical-startup
verification for the candidate. It is not formal production approval.
Authenticated external ingress, restart safety for a committed critical
write, signed supply-chain evidence, formal TLS/DNS, and operator approval
remain open gates. User-count and storage-capacity decisions belong to
0.3.3.
