# Polaris 0.3 Release TODO

Decision: **GO for the designated HTTP test host; NO-GO for formal production
promotion**. This is the archived foundation checklist for the original 0.3.0
test-host gate. The active 0.3.4 release inherits the reviewed 20-vault profile
and is summarized in [Polaris 0.3.4](../polaris-0.3.4/).

`[x]` means the named check has recorded implementation or isolated-host
evidence. `[ ]` means the check is still open. Items explicitly marked
**Deferred to 0.3.2** do not block the controlled 0.3.0 test-host release.

## Verified Candidate Checks

- [x] Polaris is the only integrated control plane. private surface is a private,
  vault-scoped surface extension.
- [x] Integrated private surface uses direct `/vault/workspaces`, `/vault/backups`, and
  `/vault/cache` mounts with no shared runtime root.
- [x] Polaris owns identity mapping, capability decisions, gateway rate
  limits, logical quota admission, lifecycle, durable jobs, and audit. private surface
  verifies the signed scope and serializes its local write.
- [x] The shared-origin gateway rejects forged, expired, replayed,
  cross-scope, CSRF, and direct-port bypass attempts in isolated synthetic
  drills.
- [x] Docker private surface ports are loopback-only. The external test host could not
  reach `9090` or the loopback-mapped test ports.
- [x] The Docker profile declares and tests 1 CPU, 512 MiB memory/no-swap,
  128 PIDs, 64 MiB tmpfs, and a 512 MiB writable layer. One-slot active-vault
  admission also passed.
- [x] The 0.3 profile pins one control plane, one gateway, one worker, a
  60-second job lease, a 10-vault ceiling, and a 256 MiB active-workspace
  quota.
- [x] Encrypted backup, staging restore, activation, rollback, cancellation,
  checksum verification, retention, off-host copy, and key recovery passed
  with synthetic tenants.
- [x] A crashed durable backup job was reclaimed without a duplicate logical
  operation and completed below the 120-second recovery target.
- [x] The HTTP test origin served the root health/readiness probes and denied
  unauthenticated private surface access. Authing browser callback, token exchange,
  session, and host-list checks passed in the isolated candidate.
- [x] The bounded 5/10-user release run passed with zero recorded errors,
  zero 5xx responses, 100% launch success, and read P95 below 500 ms.
- [x] Release preflight continues to reject mutable images, public `9090`,
  invalid profiles, and unsafe backup-key permissions. The test-host build is
  local and unsigned; external signature verification is deferred to 0.3.2.
- [x] The designated test host passed a disposable systemd restart drill and
  retained healthy existing synthetic vaults during the candidate restart
  checks.
- [x] The operator runbook covers probes, logs, job state, disk pressure, and
  rollback.
