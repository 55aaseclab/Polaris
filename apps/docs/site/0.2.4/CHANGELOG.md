# Docs Changelog

## 0.2.4 vs 0.2.3

### Added

- Customer-facing Polaris sections for onboarding, governed use, shared
  infrastructure, and member exit and handover.
- Focused sub-documents for ownership, credential switching, shared Docker
  foundations, runtime state, and handover context.

### Changed

- Polaris documentation is now organized primarily around customer product
  flows instead of older top-level technical maturity pages.
- The earlier technical notes were merged into the new section docs and
  section-level `others` pages.

### Notes

- `0.2.4` is the current frozen release snapshot.
- `latest` starts from this baseline.
