# Polaris 工作流观察台需求

在原生门户浏览当前工作区的工作流、图、运行状态和时间线。首次启动为空。接口只读，工作区标识不匹配时拒绝读取。数据单独放在私有目录。

向 Praxis Settings 提供应用自有的只读数据清单元数据。Polaris 明确作为 runtime，不参与工作台卡片。


## 运行留痕元数据

对既有获批工作区观察提供只读元数据投影。保留运行、流程标识、状态，以及实际记录的创建、开始、更新时间和版本；步骤保留标识、状态与版本，产物只给不透明引用。缺失字段保持未知，步骤及产物列表受限时保留总数。覆盖类型为运行观察，与应用提交生命周期分开，不返回命令、日志、诊断正文、输入输出、凭据或可执行流程。
